# Autonexus2

E-commerce de repuestos automotrices ubicado en Wilde, Avellaneda. 
Permite ver catálogo de repuestos, filtrar por categoría, buscar por nombre, agregar al carrito y simular pago.

**Tecnologías usadas:**
- React + Vite
- React Router DOM (HashRouter)
- Context API para el carrito
- LocalStorage para que el carrito no se borre al recargar
- CSS puro
- 2 APIs: BigDataCloud (para geolocalización) y Open-Meteo (para clima real)
